GCP ranges now provision on the GCE range-cell backend by default (`GCP_RANGE_BACKEND` defaults to `gce`). The GDC VM Runtime path is retained and can be re-selected per environment with `GCP_RANGE_BACKEND=gdc`. Added the range-scoped `GCP_RANGE_CELL_PROJECT_ID` so range cells target the real range project independently of the control-plane project.
