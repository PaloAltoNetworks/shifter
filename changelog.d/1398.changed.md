Gate the platform deploy on worker/scheduler container health. The post-deploy checks only covered the portal web tier (image digest + ALB `/health/`), so crash-looping workers (outbox drainer, reconciler, ctf-scheduler, etc.) shipped as a green deploy. A new `verify-asg-workers` step SSM-checks each in-service instance's worker containers and fails the deploy when any never reaches `healthy`, retrying to tolerate the health-start-period and a single transient restart.
