The built-image stack smoke (`scripts/stack-smoke/stack_smoke.sh`) now sets `CLOUD_PROVIDER=aws` in the portal container env. Production settings resolve and validate the active cloud backend at import (PLAT-2005) and fail closed when it is absent, so the smoke (which boots the built image with `ENVIRONMENT=production`) must supply the backend identity explicitly, exactly as a real AWS deploy does. Without it the container failed to start with `ImproperlyConfigured: CLOUD_PROVIDER environment variable is required`.
