**Guacamole session token URLs are no longer retained at rest after delivery.** The asynchronous bootstrap flow now returns the signed Guacamole URL exactly once and clears the token material from the database row in the same transaction, never persists a URL for a request that finished after its TTL expired, and runs a dedicated scheduled service that prunes expired bootstrap rows in bounded batches. A database read can no longer disclose a live RDP/SSH session URL.
