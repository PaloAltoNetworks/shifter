Made the post-deploy range smoke agent-independent. It now provisions minimal ranges built entirely from base range AMIs: `smoke_linux` (Kali attacker + Ubuntu victim, SSH probe) and `smoke_windows` (Kali attacker + plain Windows victim, RDP probe), with no XDR agent, and no longer requires the `SMOKE_LINUX_AGENT_ID` / `SMOKE_WINDOWS_AGENT_ID` secrets. The smoke validates the platform (provision, connect, teardown); XDR/agent install is scenario content exercised by real scenarios, not the smoke.
