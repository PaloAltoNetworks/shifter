Fixed the Packer base-image build (`kali`/`ubuntu`/`windows`) so it can launch a builder in a fresh or scrubbed AWS account. The base `build` job now takes its builder VPC and subnet from trusted `PACKER_BUILD_{VPC,SUBNET}_ID_<ENV>` repository variables (validated and injected as `-var`, overriding the OSS placeholders in the committed `<env>.pkrvars.hcl`) instead of reading the placeholders directly, which previously failed with `InvalidSubnetID.NotFound`.
