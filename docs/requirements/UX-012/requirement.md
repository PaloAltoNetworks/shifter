# UX-012: Visible focus indicators

## Statement

All interactive elements shall display a focus indicator meeting WCAG 2.4.11 Focus Appearance criteria. The default browser focus indicator shall not be removed or suppressed without an equivalent or stronger replacement defined in the design system.

## Rationale

Removing default focus styles without replacement is one of the most common accessibility failures. A consistent, visible focus indicator across the design system makes keyboard navigation usable and is a prerequisite for keyboard-first users to have any reasonable experience.
