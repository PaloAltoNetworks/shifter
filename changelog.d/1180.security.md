Removed the Guacamole runtime credentials (`POSTGRESQL_PASSWORD`, `JSON_SECRET_KEY`) from the Helm chart contract so they can no longer be persisted into chart values or Helm release history. The `shifter` chart now references the `guacamole-runtime` Kubernetes Secret by name only; the Secret is created out of band by the deploy bootstrap (`kubectl apply` from the provider secret store), which remains the single runtime copy alongside Secret Manager. The chart's raw-payload `Secret` template and the deployment's checksum-over-secret annotation were removed, closing a latent secret-exposure path (#1180).
