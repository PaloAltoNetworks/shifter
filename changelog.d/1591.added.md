Documentation is now a single public site: all product and engineering docs are consolidated under top-level `docs/`, built with mkdocs (Material), and published to GitHub Pages by `.github/workflows/docs.yml` (PRs get a strict build check; pushes to the default branch publish). The in-app login-gated Django documentation reader is retired; the portal's Docs and Help links point at the hosted site. Internal design notes, machine registries, deprecated content, and scratch dirs are kept in-repo but excluded from the published site (ADR-038; #1591).
