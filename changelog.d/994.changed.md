**The `mission_control` → `engine.services` layer-import boundary is now enforced per-symbol.** The presentation layer may import from `engine.services` only the sanctioned realized-runtime/data-plane symbols (`connect_terminal`, `SSHConnection`, `get_ssh_connection_info`, `get_rdp_connection_info`, `connect_ngfw_terminal`, `get_ranges_for_ngfw`); any other `engine.services` symbol, or a bare `import engine.services` module import, is a layer-import violation, so control-plane operations keep fronting through `cms.services` (ADR-001-R4).
