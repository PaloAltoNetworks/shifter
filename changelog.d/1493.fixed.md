Granted the GitHub Actions CI role read-only access to AWS-owned public SSM parameters under `arn:aws:ssm:<region>::parameter/aws/service/*`. The scenario bakes (techvault and polaris golden ranges) resolve current base AMIs through these public parameters, and the management policy previously scoped SSM read to `parameter/shifter/*` only, so the bakes failed with an `AccessDeniedException` on the Canonical Ubuntu and Amazon Linux AMI-ID lookups.
