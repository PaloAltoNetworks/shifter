Fixed the AWS POLARIS/scenario Packer bakes so they can complete in a fresh account. `polaris-dc` now declares the `dc_dsrm_password` variable and passes `DC_DSRM_PASSWORD` through to `promote-bake.ps1`, so the per-build DSRM secret (`PKR_VAR_dc_dsrm_password`, masked) actually reaches the forest promotion, matching the GCP pipeline; previously the AWS build never wired the secret through, so `promote-bake.ps1` refused to bake. `polaris-vm` and `techvault` AMI descriptions now use an ASCII hyphen instead of a Unicode dash, which EC2 `ModifyImageAttribute` rejects (the bake built the image, then failed at the description and rolled back the AMI).
