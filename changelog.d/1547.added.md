Added a first-class AWS Packer template for the Polaris domain controller (`shifter/packer/polaris-dc.pkr.hcl`, wired into `packer.yml` as the `polaris-dc` AMI type). It is the amazon-ebs twin of the GCP `dc-prebaked` template: it bakes a pre-promoted `boreas.local` DC (OUs/users/SPNs/DCSync ACL/shares via `a2_setup.ps1`) with OpenSSH Server preinstalled (required by the range provisioner's DC setup). This replaces the previous ad-hoc DC bake, which produced AMIs missing OpenSSH.
