Made the platform→provisioner ACES `ProvisioningPlan` transport versioned and fail-closed (ADR-032-R7). The provisioner now validates the transport contract version and the `aces-sdl` producer version and rejects unknown resource types, malformed payloads, duplicate identities/aliases, and dangling network references before any cloud mutation, so version skew or a malformed plan can no longer silently provision a partial or incorrect topology.
