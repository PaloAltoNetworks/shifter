Bounded the CPU cost of organizer-authored CTF regex flags, closing a regular-expression denial-of-service path (CWE-1333 / CWE-400) where a crafted pattern/input pair could pin a request worker. Regex flags are now rejected at creation time when over-long or uncompilable, participant submissions are length-capped before matching, and matching runs under a per-call timeout that fails closed (treated as an incorrect submission) rather than blocking the worker. Limits are tunable via `CTF_REGEX_FLAG_MAX_PATTERN_LENGTH`, `CTF_REGEX_FLAG_MAX_SUBMISSION_LENGTH`, and `CTF_REGEX_FLAG_MATCH_TIMEOUT_SECONDS`.
