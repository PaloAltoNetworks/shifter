Published the backend-bundle contract as a committed, versioned JSON artifact (`shifter/installation/published_contract/`) generated from the Pydantic contract and registry. The published schema encodes the contract's security-relevant validators, and `installation.validate_published_bundle` is a parity-complete portable validator for downstream bundle authors. Adds a `shifter-config contract` CLI and CI gates for drift, unversioned breaking changes (a recursive full-surface compatibility differ against immutable per-version snapshots), registry conformance, and append-only snapshot immutability (#1323).
