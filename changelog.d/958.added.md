Added `shifter-config render`, which generates the range egress allowlist's provider Terraform bridge variables (AWS `victim_allowed_cidrs`; GCP `range_egress_mode` + `range_egress_allowed_cidrs`) directly from the validated `settings.range_egress` policy in `shifter.yaml`. Operators now render the deployment tfvars from the single authoritative source instead of hand-maintaining a second gitignored allowlist copy, so the configured policy and deployed firewall rules cannot drift.
