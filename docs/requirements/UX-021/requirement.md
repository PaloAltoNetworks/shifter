# UX-021: Predictable interaction patterns

## Statement

Hover, focus, active, disabled, loading, and error styling shall be consistent across all components in the design system. The same interaction in two different surfaces shall feel and behave the same way. The design system shall document the canonical pattern for each interaction state.

## Rationale

Predictability is a core usability heuristic. When the same control behaves differently in different parts of the app, users spend cognitive effort relearning what should be muscle memory. Consistency is also what makes a product feel "designed" rather than assembled.
