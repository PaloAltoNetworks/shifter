`gdc-bootstrap` now builds the ABM/GDC VM-Runtime substrate only for the `gdc` range backend; the default `gce` backend deploys the keyless GKE control plane straight through. The substrate created a `baremetal-gcr` service-account JSON key, which fails under orgs that enforce `constraints/iam.managed.disableServiceAccountKeyCreation` and blocked the sole documented GCP standup entrypoint even for `gce` deployments that never use the substrate. A new `--range-backend {gce,gdc}` flag (default resolved from `GCP_RANGE_BACKEND`, else `gce`) selects the path; the `gce` path creates no service-account keys.
