Native CTF scoring now serves the live scoreboard, participant rank, and flag-submission responses from materialized per-participant and per-team leaderboard columns instead of recomputing the entire event board from raw submissions/awards on every request. Flag submissions, the participant dashboard, and the auto-refreshing scoreboard poll no longer scale their database work with participant count, so native CTF scoring stays responsive under event load. The materialized state is maintained incrementally on solve/award/disqualification/team-change, is rebuildable from the authoritative submission and award rows via the new `ctf_recompute_leaderboard` management command (and automatically on event completion), and falls back to the exact authoritative recompute for frozen and bracket-filtered team views, so rankings, tie-breaks, freeze, and visibility semantics are unchanged.
