Portal: the RDP/SSH access path no longer blocks on AWS Secrets Manager. Credential resolution now runs in the bounded Guacamole bootstrap worker (not the request thread), the Secrets Manager client has explicit connect/read timeouts, per-range credentials are cached for a short TTL, and terminal-websocket connect/audit work runs on a dedicated executor. A stalled Secrets Manager or a terminal connect storm no longer head-of-line-blocks `/health` and page renders on an ASGI worker.
