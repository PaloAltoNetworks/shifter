The portal can now send SES email (CTF magic-link invites, alarm notifications) from the locked-down private tier. `django_ses` uses the SES API, but the private tier has no internet egress to the public SES endpoint, so every outbound email silently hung until timeout. A VPC interface endpoint for the SES API (`com.amazonaws.<region>.email`) is added to the portal endpoint set, keeping SES traffic on the VPC-local path like the other 18 service endpoints; no SMTP switch or credentials are required.
