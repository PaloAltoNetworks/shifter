Test tooling now matches CI from a clean checkout and reports trustworthy quality metrics (REV1 Q6/Q7). A repository `Makefile` runs each package's suite with the same dependency sync and environment posture CI uses (`make help` lists the targets), and the platform `conftest.py` establishes `DJANGO_DEBUG`/`TEST_DB_BACKEND` and pins `LOCAL_PROVISIONER` off so a bare `uv run pytest` no longer inherits production HTTPS posture or shells out to a real provisioner. Production coverage now excludes tests (so the number reflects owned code, not tests covering themselves) and enforces per-package `fail_under` floors. Unawaited-coroutine and resource warnings fail the platform suite, and third-party deprecations are baselined as narrow per-message allowances with a removal owner (see `docs/dev/testing.md`) instead of being broadly suppressed.
