Pre-promoted domain-controller images can now be baked for any domain from one parameterized Packer template (`dc-prebaked.pkr.hcl`) driven by per-purpose profile var-files in `shifter/packer/gcp/dc-profiles/`. To add a DC for a new domain, copy a profile, supply its AD-content script, and run the Packer GCE build with `dc_profile=<name>`; it publishes image family `shifter-<purpose>-dc`. The former `polaris-dc` template becomes the default `polaris` profile (BOREAS.LOCAL). The parameterized runtime-promotion path is retained but unused (pre-bake keeps time-to-serve low).
