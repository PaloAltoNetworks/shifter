Inter-service event handlers now consume typed `TypedDict` payloads instead of untyped `dict[str, Any]`. Bus (SNS/SQS) event contracts live in `shared.messages.payloads` (`RangeStatusUpdatedPayload`, `RangeProvisionedPayload`, `NGFWEventPayload`) and Django Channels `group_send` contracts in `shared.channels.payloads` (`RangeStatusChannelEvent`, `NGFWStatusChannelEvent`). Engine/CMS/Mission Control handlers and the Mission Control websocket consumers are annotated with these, so mypy now catches event field typos and type mismatches at the call site. This is a static-typing change only: envelope parsing, `ResourceStatus`/ownership/`RangeRef` validation at the untrusted SQS/channel boundary is unchanged.
