The self-hosted runner Terraform (`platform/terraform/global/github-runner`) gains an explicit ADR-004-R20 opt-in, `allow_default_vpc`, for account-default-VPC placement. The guard still fails closed by default; when opted in (aws-dev/aws-proof set it) the stack auto-resolves the default VPC and one of its subnets, so no live VPC/subnet IDs are committed (ADR-004-R14). This reconciles the #1222 non-default-VPC mandate with the reality that deploys have always run runners in the default VPC. The pinning checker, its tests, ADR-004-R20, and the runner runbook/README are updated to match, and issue #1437 tracks reassessing the durable placement design.
